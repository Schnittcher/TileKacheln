# Changelog

## 16.06.2026 - Version 1.0 Build 7 (Beta Version)

### Neu
- RolloKachel: Es kann zwischen Rollo und Markise gewählt werden.
- RolloKachel kann optional den aktuellen Status und die aktuelle Position anzeigen.
- KlimaKachel: Außentemperatur, Luftfeuchte innen/außen, Luftverteilung und Modi werden nun als Icons dargestellt.
- WhirlpoolKachel: Variable für Licht, Chlor und pH.
- ThermostatKachel: Es kann ein 2. Ventil hinterlegt werden.

## 28.05.2026 - Version 1.0 Build 6 (Beta Version)

### Neu
- VentilKachel.
- KlimaKachel.
- Bei allen Kacheln: Neues Konfigurationsfeld „Symcon-Akzentfarbe verwenden" (Standard: aktiviert). Die Akzentfarbe folgt automatisch dem Symcon-Theme statt einer fixen Eigenfarbe.

### Fixes
- ThermostatKachel: Ziel-Temperatur in Soll-Temperatur umbenannt.

## 21.05.2026 - Version 1.0 Build 5 (Beta Version)

### Neu
- RolloKachel: Beim Stopp-Button kann nun eine Integer- oder Boolean-Variable hinterlegt werden, dazu der Wert, der übermittelt werden muss, und eine Automatik-Funktion.

### Fixes
- RolloKachel: Invertierung korrigiert, Aktions-Buttons verschoben.

## 21.05.2026 - Version 1.0 Build 4 (Beta Version)

### Neu
- WhirlpoolKachel: Leistung und Energiezähler.

### Fixes
- RolloKachel: Kommt nun mit allen Werten zurecht und rechnet intern auf 0-100 % um.
- Allgemeine Design-Fixes.

## 20.05.2026 - Version 1.0 Build 3 (Beta Version)

### Neu
- ThermostatKachel: Die Ventilposition kann Boolean sein, die Zieltemperatur kann auch nicht schaltbar sein.
- RolloKachel: Stopp-Button (sendet die aktuelle Position), 4 frei definierbare Positions-Buttons, die Positionsvariable kann invertiert werden.

## 20.05.2026 - Version 1.0 Build 2 (Beta Version)

### Neu
- HeizoeltankKachel.
- BrauchwasserKachel.
- ThermostatKachel: Ventilstellung, Luftfeuchte kann nun Integer oder Float sein.
- RolloKachel kann nun Integer und Float, die Rollo-Position ist zusätzlich als Slider verfügbar.

### Fixes
- Die Kacheln kommen auch mit dem hellen Design zurecht.
